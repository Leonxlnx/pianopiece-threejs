# Floor joinery refinement

Reduced visible floor joints from 5–7 mm to 1.5 mm and bevel radius from 2 to 0.7 mm. Board centers, upper walking surface and instance count stay fixed. Both paired native views (0.8 and120.5s) have GL_NO_ERROR; root inspected the opening pair and accepted the less grid-like surface. The floor reflector is raised from the coplanar .001m height to .0025m, clearing the board tops by1.5mm. The native renderer omits that weak reflector, so its flicker behavior requires a browser with WebGL; that check remains unavailable.
