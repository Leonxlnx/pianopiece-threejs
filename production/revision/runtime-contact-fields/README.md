Optional per-note contact controls
==================================

contactZ is the key contact depth in scene metres. thumbOpposition is a rotation in radians of the complete thumb flexion plane around its base-to-tip axis. Both are optional, and the absence of either retains the previous behavior. These values propagate through active targets, fallback grip cost/cache identity, and reconstructed held endpoints for released fingers.

Baseline performer source: fedec1a81e52ccfc87527b3522100d8a6facd2674b6ed2a7b145e50f48cdc184 (available at Git checkpoint f6989a1). Candidate source: f0407941995f70ecafecebe9559e0289716620f656b51affcfe279aade9c94b8.

Default-field parity checks use the b156 public score and the exact 77423a38 model. At 20 times, all 840 hand/wrist bone pairs have identical world positions and local quaternion components. The retained original reproduction script runs in the endpoint-fix scratch layout described by the composer handoff; it is not a standalone command from this archive directory.

This integration enables new scored contact positions. It does not approve any provisional score, inactive reference, or transition. Full merged geometry and playback review remain separate.
