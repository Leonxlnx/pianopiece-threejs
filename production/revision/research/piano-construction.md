# Open-lid grand piano review

Read-only review of `/workspace/sites/daybreak-piano-film/app/performance/piano.ts` on 2026-09-05, before the parent's in-progress construction changes. No checkout files were modified. Findings describe that snapshot; proposed dimensions/placements are visual implementation decisions unless a source is stated.

## Five highest-value corrections

1. **Give the bass a distinct crossing bank and height.** The current `for(i<88)` generates one monotonic string fan with identical start/end heights for every register. Introduce a separate copper-wound bass bank crossing above the tenor bank, with a distinct bass bridge height. The visual payoff is the unmistakable layered geometry of a modern grand. Preserve the existing one/two/three-string progression, but make gauge change by register visible in geometry for the bass. Steinway identifies the Model D scale as overstrung; Yamaha confirms wound bass versus bare upper wire and changing string multiplicity. Sources: https://www.steinway.com/pianos/steinway/grand/model-d ; https://www.yamaha.com/en/musical_instrument_guide/piano/mechanism/mechanism004.html

2. **Make strings bear on bridges instead of merely passing near a decorative curve.** The current single `TubeGeometry` bridge is independent of every string endpoint. Use a short bass bridge and a longer curved tenor/treble bridge, shaped as shallow wooden rails with a flattened cap rather than round tubing. Derive string support/contact positions from the bridge curves, continue the non-speaking tails toward hitch pins, and add sparse paired bridge pins at close-view resolution. The soundboard sits beneath and supports the bridges. Yamaha explains the two bridges and their hardwood construction; its mechanism guide explains transfer of string vibration through them. Sources: https://hub.yamaha.com/pianos/p-acoustic/a-brief-guide-to-piano-tonewoods/ ; https://www.yamaha.com/en/musical_instrument_guide/piano/mechanism/mechanism002.html

3. **Place one small damper head per damped string course, above its actual wires, and keep the highest treble undamped.** The reviewed class declares `dampers` but never constructs or animates them. Heads should be restrained wood shapes with off-white felt underneath, supported by thin vertical wires; felt shape varies by register. The individual key lifts its corresponding head, while sustain lifts the damper bank even after keys release. Keep head travel subtle and return felt to wire contact. Do not add a row spanning all 88 notes; Yamaha confirms the highest region has no dampers, but the exact cutoff is model dependent and not specified here. Hammers strike from below and should not be confused with the visible damper heads. Sources: https://www.yamaha.com/en/musical_instrument_guide/piano/mechanism/mechanism003.html ; https://faq.yamaha.com/my/s/article/000012300 ; https://www.yamaha.com/en/musical_instrument_guide/piano/selection/ ; https://www.yamaha.com/en/musical_instrument_guide/piano/mechanism/mechanism002.html

4. **Make the gold frame read as a cast plate with connected webs and string clearance.** The current ring plus four straight cylindrical crossbars looks like separate rods; their centres/radii lie close enough to the string plane to create possible intersections. Use broad cast webs around open string fields, rounded junctions, a few mounting bosses/bolts, and deliberate clearance where strings pass. Preserve exposed spruce through the openings. Use a restrained bronzed/lacquered surface rather than highly polished yellow brass everywhere. Steinway describes a gray-iron, bronzed and lacquered plate; Yamaha describes the plate's structural role. Sources: https://www.steinway.com/pianos/steinway/grand/model-d ; https://www.yamaha.com/en/musical_instrument_guide/piano/manufacturing/manufacturing003.html

5. **Attach visible hardware to functional endpoints.** The snapshot has 176 brass cylinders in a two-row grid, while its multiplicity rule generates 219 string segments; positions are independent of string starts. Generate tuning-pin positions from each individual wire/course, with staggered rows in the front pinblock, small coils at pin heads, agraffes or a bearing bar at the speaking-length start, and hitch pins after bridge tails. Use steel/dark nickeled pins rather than the same gold as the plate; reserve brass for appropriate guides and lid hinges. Also derive the lid-prop tip from the transformed underside point so the independent hard-coded endpoint does not intersect the lid thickness when lid angle changes. Sources: https://www.yamaha.com/en/musical_instrument_guide/piano/mechanism/ ; https://www.steinway.com/pianos/steinway/grand/model-d ; https://www.yamaha.com/en/musical_instrument_guide/piano/manufacturing/manufacturing004.html

## Efficient implementation structure

Use a shared `StringCourse` record containing MIDI note, register, wire count, start/pin positions, speaking start, damper contact, bridge contact, hitch positions, and wire height/gauge. Generate strings, pins, bridge supports and dampers from it. This prevents independent meshes drifting apart as the layout changes. A plausible simplified course layout matters more from the open-lid camera than adding many disconnected tiny parts.

The existing 219-string count is not itself an error: Yamaha explicitly says total counts vary by model. The error is the visibly independent hardware layout, not failure to hit a universal total of 230. Likewise, a faithful brand-specific reproduction would need a chosen instrument reference; the recommendations here target a plausible original concert grand.
