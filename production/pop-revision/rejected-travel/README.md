# Rejected world-space finger travel candidate

This isolated candidate combines 49 left-hand and 43 right-hand route profiles on the shared world-space flight solver. It is retained to explain why local collision-clear fits were not accepted as the final performance. It has not replaced the application rig.

The full 60 Hz diagnostic preserves all 5,055 assigned-pad samples within ±3 mm and a maximum contact marker error of 0.874 mm. Nevertheless, 5,224 of 109,024 nonthumb observations exceed the shape review bounds; peak dorsal elevation is 89.53° and backward PIP movement is 25.29 mm. Actual closeups also show tightly curled released fingers below the elevation limit. The solver frequently saturates its 87° PIP bend cap when a travel target approaches the knuckle too closely.

`manifest.json` identifies the exact base, source, compiled rig and score. The patch reconstructs only this rejected experiment. The numerical report retains its failures; it is not a substitute for a final 240 Hz audit. Root is replacing the shared resting/travel behavior before integrating additional local profiles.
